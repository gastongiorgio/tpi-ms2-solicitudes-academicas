# TPI - Metodología de Sistemas II

## Sistema de Gestión de Solicitudes Académicas

Proyecto desarrollado para el Trabajo Práctico Integrador de Metodología de Sistemas II.

### Integrantes

- Gastón Armando Giorgio
- Matías Ariel Deluca
- Emanuel Andres Meshler

### Tecnologías

- Backend: Node.js + Express
- Frontend: React
- Base de datos: PostgreSQL

### Objetivo

Desarrollar un sistema simple de gestión de solicitudes académicas y utilizarlo como base para analizar calidad interna y externa, deuda técnica, code smells, principios SOLID, Clean Code, refactoring, pruebas y code review.
