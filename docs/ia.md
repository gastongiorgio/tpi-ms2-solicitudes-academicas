# Registro de uso de Inteligencia Artificial

## Herramienta utilizada

ChatGPT - OpenAI

## Finalidad

La herramienta se utilizó como apoyo durante el desarrollo del Trabajo Práctico Integrador para:

- interpretar y organizar los requerimientos de la consigna;
- definir un alcance adecuado para el sistema;
- planificar la estructura inicial del proyecto;
- recibir orientación sobre Git y organización del repositorio;
- comprender la implementación del backend con Node.js y Express;
- revisar posteriormente problemas de calidad interna y alternativas de refactoring;
- apoyar la redacción y organización de la documentación.

## Grado de intervención

Las respuestas generadas por la herramienta fueron utilizadas como orientación y material de apoyo.

El equipo realizó la ejecución de los comandos, implementación del código, pruebas, revisión de resultados y toma de decisiones sobre el proyecto.

Todo el código y la documentación incorporados al repositorio deberán ser comprendidos y validados por los integrantes antes de la entrega.

## Interacciones relevantes

### Planificación inicial

Se utilizó IA para analizar la consigna del TPI y definir un sistema de complejidad acotada que permitiera aplicar calidad interna y externa, deuda técnica, code smells, SOLID, Clean Code, refactoring, pruebas y code review.

A partir de este análisis se seleccionó como caso de estudio un Sistema de Gestión de Solicitudes Académicas.

### Organización del proyecto

Se utilizó IA como apoyo para definir una estructura inicial con:

- backend en Node.js y Express;
- frontend en React;
- base de datos PostgreSQL;
- documentación y evidencias dentro de `/docs`.

### Desarrollo del backend inicial

Se utilizó IA como guía para implementar y comprender los primeros endpoints de la API y realizar pruebas manuales de las operaciones principales.
